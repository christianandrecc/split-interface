## 1. Inspector-owned immutable catalog and exact public value calls

PDF1 remains `split.pdf.inspection.fixture.proposal.v0.1` / `pdf1-curated-originals-v1` / `syntheticFixture`. The future `PDF1Inspector()` installs its **own** closed immutable approved catalog and private issuer/world instance at initialization. Records come from the independently frozen source/catalog/index, never a supplied handle, body, resource manifest or callback. No public initializer/factory accepts a catalog, expected pages/hash, world, parser implementation, acceptance flag or arbitrary records. Two inspectors A/B using identical strings/bytes still have distinct private issuer identities.

A `PDF1AssetHandle` has private construction and immutable issuer-instance identity plus asset ID only. It contains no expected record/pages/digest/catalog. Every consuming call checks issuer identity against **this inspector's installed world**, then resolves its own record. Copying a handle preserves its issuer; a B-issued handle at A rejects before copy/hash/PDFKit, even if all strings and bytes coincide. A resource filename or public dataset string is not a world issuer.

The sole public calls below are synchronous/main-actor local fixture operations; no serialization, wire schema, endpoint, account permission, execution readiness or transferable authorization is selected. Their input value fields are exact; programmatic optionals are not JSON null variants or changes to AF1.

| Public entry point | Exact input and result boundary |
| --- | --- |
| `resolveAsset(identity: PDF1AssetIdentity)` | Identity has `boundaryID,datasetID,origin,assetID,role,documentID:String?,mediaType`. Match the three literals, then the installed record's exact ID/intrinsic role/document/media. Returns `.resolved(PDF1AssetHandle)` or typed identity rejection; no parser or arbitrary-record construction. |
| `inspect(copying: Data, asset: PDF1AssetHandle)` | **Sole public per-asset parser boundary.** Returns `.inspected(PDF1InspectionFacts)` or `.rejected(PDF1Rejection)`. All identity, bounded owned intake, retained integrity and actual PDFKit checks below are mandatory. No second public owned-input/parser route. |
| `validateGroup(identity: PDF1GroupIdentity, members: [PDF1GroupMember])` | Group identity has `boundaryID,datasetID,origin,groupID`; only Q1/Q2 exist. Each member has `position:Int,asset:PDF1AssetHandle,body:Data`. Resolves expected group on the checking side, validates the **entire** ordered set and retained bytes. Returns `.groupCorrespondenceValidated(PDF1GroupFacts)` or typed rejection. It never initializes PDFDocument and is not a package/inspection/readiness result. |

Intrinsic records use IDs `doc-a`/`doc-b`, role `documentSample`, document IDs `pdf1-document-a`/`pdf1-document-b`; `evidence-sample` has role `completionEvidenceSample` and no documentID. The three other existing planned IDs (`malformed-matching-hash`, `encrypted-locked`, `encrypted-empty-password`) have supported role `negativeSample`, no documentID and their own retained byte expectations. All six have nominal mediaType `application/pdf`, including the malformed `.bin` resource. Expected pages are 1 except doc-b's 2; for negatives this is an intended comparison input, **never an observed fact**. Negative classification, filename/extension or media/tag must not skip actual initialization or force a fabricated rejection. Original resource names remain unchanged.

Group membership is separate from intrinsic role: Q1 is exactly `(0,doc-a,documentSample,pdf1-document-a),(1,evidence-sample,completionEvidenceSample,nil)`; Q2 is exactly `(0,doc-a,documentSample,pdf1-document-a),(1,doc-b,documentSample,pdf1-document-b),(2,evidence-sample,completionEvidenceSample,nil)`. Thus evidence has no global intrinsic order; its position is 1 in Q1 and 2 in Q2. No sort, deduplication, omission, truncation or repair.

`validateGroup` rejects in this order: unsupported group identity; count other than its expected 2/3 (also never above 3); foreign/unknown handles; duplicate asset IDs; any array-index/declared-position/expected ID/role/document-slot mismatch; actual body bounds/aggregate; retained length/digest mismatch. Every membership/bounds check precedes additional ownership copying/hash. Check actual counts, not declared metadata: each body 1…1,048,576 bytes; aggregate at most 3,145,728 using remaining-budget subtraction without overflow. Check the whole set before success, not a prefix. These small fixture budgets do not bound an earlier caller allocation or hostile parser work. With at most 3 individually bounded files, an aggregate-only overflow is redundant; do not invent an independent passing full-budget asset or claim that unique fault was demonstrated.

Group facts contain only groupID, ordered `(position,assetID,role,documentID,byteLength,sha256)` value facts and aggregateByteLength. Inspection facts contain only boundary/dataset/origin, asset identity/role/documentID, byteLength/sha256 and actual page/encryption/lock facts. Neither result exports handles, Data, PDFDocument/PDFPage, URLs, mutable metadata bags, a grant, display/share eligibility or finality. Group success cannot substitute for inspecting each asset, or vice versa.

## 2. Same product intake/parser path and typed observable branches

Keep the original three source/two test paths. `PDF1AssetValues.swift` holds typed values and the opaque internal owned-input value; `PDF1FixtureCatalog.swift` holds the private immutable world/issuer, closed resolvers/groups and fixed privileged test-world factory; `PDF1Inspector.swift` holds group validation and the common product intake/integrity/PDFKit path. `PDF1DatasetBoundaryTests.swift` exercises real resolver/group/world behavior; `PDF1InspectionTests.swift` exercises real parser branches, owned input and faults. No extra public capability, target/file or dependency is needed by this clarification.

The public copying inspection calls the same **internal** `intake(copying:asset:)` and `inspectOwned(_:asset:)` that `@testable` tests may use. Intake checks current inspector/handle binding, actual span bounds and retained length before synchronously copying **exactly** that span into independent storage. Its private constructor binds storage to this world, asset and immutable catalog record; no Data/storage accessor escapes. `inspectOwned` rechecks inspector/handle/snapshot binding and retained length/SHA256, then uses that same owned snapshot in the single real `PDFDocument(data:)` call. The group validator reuses owned intake/integrity without parsing. No detached test-side “inspection passed” helper can replace these functions.

For bridging/subview tests: use actual known PDF bytes in an externally mutable backing with nonzero offset and prefix/suffix sentinels. Complete synchronous intake first, then mutate the backing source while **no copy/parser is running**, then invoke the same `inspectOwned` product path. Original retained digest and actual pages must still match. Include bridged NSMutableData and a nonzero-offset span; do not assume a Data wrapper owns it. A snapshot at another inspector or for a different handle rejects binding before PDFKit. Caller mutation is not concurrent-race evidence. No test mutates or receives the private snapshot storage.

Normative stages are `identity,group,bounds,integrity,initialization,encryption,pageComparison,inspection`. Reasons are `unsupportedBoundary,unsupportedDataset,unsupportedOrigin,unknownAsset,assetIdentityMismatch,foreignWorld,unknownGroup,snapshotBindingMismatch,memberCountMismatch,duplicateAsset,slotMismatch,bodySizeOutOfRange,groupBytesExceeded,byteLengthMismatch,digestMismatch,initializationFailed,encryptedOrLocked,pageCountMismatch`. Page mismatch carries typed expected/actual integers; other structural mismatches need no dynamic diagnostic bag. Unknown asset precedes matching its role/document/media. These are PDF1 fixture reasons, not AF1 Failure codes or service errors.

Each outcome carries typed observations: `parserInitializations:0|1`, `initialized:Bool?`, `isEncrypted:Bool?`, `isLocked:Bool?`, `actualPages:Int?`. They are written from the **actual product initializer/properties**, not injected by tests; the counter increments only at that real call site. No API accepts an observation, PDFDocument or parser-success callback.

| Product branch, in order | Required stage/reason and actual observations |
| --- | --- |
| Unsupported identity/foreign world/group/bounds/retained integrity | Relevant pre-parser stage/reason; parserInitializations=0 and all optional observations absent. No made-up lock/page facts. Group success also has0/no parser observations. |
| Real PDFDocument initialization returns nil | initialization/initializationFailed; initializations=1, initialized=false; encryption/lock/pages absent. Matching-hash malformed must reach this branch. |
| Initialization succeeds; isEncrypted OR isLocked | encryption/encryptedOrLocked; initializations=1, initialized=true, both real flags recorded. Locked negative must be true/true; empty-password negative true/false. actualPages absent: reject **before reading/comparing page count**, regardless of its expected value. |
| Unencrypted/unlocked; actual pageCount is0 or differs from retained expectation | pageComparison/pageCountMismatch(expected,actual); initializations=1, initialized=true, flags=false/false, actualPages recorded. |
| Exact nonzero expected pages and flags=false/false | inspection/.inspected with those real facts, original byte identity and initializations=1. No eligibility follows. |

For all supported matching-hash negative records, run the actual initializer; their QA tags never choose a branch. If the malformed input is repaired, flags differ or initialization unexpectedly fails, preserve the actual stage/facts and block asset acceptance instead of converting it into the desired rejection. There is **no explicit password argument, unlock/decrypt call or plaintext rewrite** in the inspector. PDFKit's automatic empty-password opening and possible internal decryption/caching are permitted framework behavior, not claimed absent. No PDF reserialization; verify the owned snapshot is unchanged before/after inspection. That preservation check is not a replacement for comparing its digest with the installed expected record.

## 3. Privileged test worlds and same-assertion discriminators

The fixed internal test-world factory has no caller-supplied record/pages/digest parameter or bypass flag. Its closed cases are `docAPageMismatch` and `docAParseableSubstitution`; approved public initialization cannot select them. It installs a separate immutable world **on a new test inspector**, which issues its own handles through the ordinary resolver. It does not mutate the approved world or let a foreign handle bring a new expected record into another inspector. Freeze test records from independently reviewed known assets before execution; no future hash/offset is invented here.

`docAPageMismatch` retains the exact approved doc-a identity, bytes, length and digest but expects 2 pages. Resolve its own handle at that test inspector and run the **same full copying inspection** on real one-page doc-a. Identity/integrity must pass, one real initialization must occur, flags must be false/false and the exact rejection must be pageComparison/pageCountMismatch(expected:2,actual:1). Unsupported identity, digest mismatch or a detached page-helper assertion does not satisfy the test.

For a digest-only control, later freeze a unique one-character ASCII content-stream sentinel mutation of uncompressed doc-a (not its xref/structure), preferably preserving exact length and page count. Record the independent golden location/replacement and resulting hash only after assets exist. This is an in-memory QA derivative, **not a seventh resource or accepted original**. The fixed `docAParseableSubstitution` test world retains its independently frozen substituted-byte record/expected 1 page, and ordinary product inspection there must genuinely report one unencrypted/unlocked page. At the approved inspector, the identical substituted bytes with the approved doc-a handle must reject integrity/digestMismatch before parsing. Thus malformed or wrong-size bytes cannot falsely stand in for the promised digest-only control.

| Same assertions on safe candidate and reviewer-local fault | Required discrimination |
| --- | --- |
| Omit only installed expected-digest comparison; retain ownership, length and real parser | Safe approved-world substituted-input test expects integrity/digestMismatch and zero initializations. Fault reaches the same actual product parser and changes outcome (calibrated still-parseable one-page data); those exact assertions fail. Pre/post byte-preservation equality can still hold and must not mask this missing oracle check. |
| Drop **isEncrypted** predicate while retaining **isLocked** | Safe automatically-unlocked encrypted test expects encryption/encryptedOrLocked with true/false. Fault must fail the same branch/fact assertions; a locked-only negative is insufficient. No test-side forced encrypted rejection. |
| Omit the product expected-page comparison | Safe fixed page-mismatch-world full-path test expects expected2/observed1 rejection after real initialization. The fault changes that actual product-path outcome and fails the same assertions. Testing a detached comparison function does not close this control. |

The real group validator has separate positive Q1/Q2 controls and negatives for B-for-A, A/B swap, duplicate, omit, extra, wrong declared position, evidence in a document slot, wrong role/document correspondence, body substitution and foreign-world coincident-string/byte handles. Successful individual inspections of each reordered file do **not** satisfy these checks. Assert the specific group/identity/integrity reason and zero PDF initializations; a self-consistent supplied list/body/adjacent manifest cannot replace the installed group/catalog. Missing/wrong role/document identity may reject during ordinary resolution; use legitimate evidence/B handles in the wrong slots to reach the group validator itself.
